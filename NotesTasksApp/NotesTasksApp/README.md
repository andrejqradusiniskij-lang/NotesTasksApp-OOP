# Менеджер нотаток та задач з тегами (NotesTasksApp)

Настільний застосунок для створення, редагування, пошуку та фільтрації нотаток, задач і чек-листів із системою тегів, багатопотоковою індексацією слів та експортом звітів у формат XML.

## Вимоги до системи
- Python 3.14 (або Python 3.11+)
- Бібліотека `customtkinter`
